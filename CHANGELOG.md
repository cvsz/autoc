# Changelog

All notable changes to ggtmoni are recorded here. The project follows a
lightweight semantic-versioning style for published package and executable
releases.

## [1.0.0] - 2026-07-31

- Added the shared countdown model and ordered `.env` slot parser.
- Added web, Tkinter GUI, and terminal interfaces.
- Added live file reload and masked display values.
- Added standard-library regression tests.
- Added PyInstaller Windows 11 GUI packaging and GitHub release automation.
- Published the first package to PyPI.
